# WAMP glossary

One name per thing. UI language: English (default; confirm in app-brief).

| Term | Means | Not |
| --- | --- | --- |
| Track | One audio file in the Library or Queue | song, item, entry |
| Queue | The ordered list of tracks that plays now and next | current playlist, now playing list |
| Playlist | A named, saved list of tracks | list, mix |
| Library | All tracks from the folders the user added | collection, catalog |
| Station | An internet radio stream | channel, feed |
| Play / Pause | Start or hold playback | resume, stop (Stop is separate) |
| Stop | End playback and return to the start of the track | halt |
| Next / Previous | Go to the next or previous track in the Queue | skip, back |
| Seek bar | The bar showing and changing the position in a track | progress bar, scrubber |
| Volume | Output loudness of WAMP | gain, level |
| Shuffle | Play the Queue in random order, each track once | random |
| Repeat | Replay the Queue (All) or the track (One) | loop |
| Add to Queue | Put a track at the end of the Queue | enqueue, append |
| Remove from Queue | Take a track out of the Queue (the file stays) | delete |
| Open Files… | Choose audio files from disk and play them | import, load |
| Unavailable | A track whose file cannot be found or read | missing, broken |
